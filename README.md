# ¿Quien es Trian?
¡Bienvenido a mi espacio!

Soy Trian, creador de códigos y sistemas para Bot Designer For Discord (BDFD). Me dedico a desarrollar comandos, crear sistemas para bots y compartir recursos que puedan ser útiles para otros miembros de la comunidad.

Este repositorio es una pequeña presentación sobre mí, mis intereses y mi camino como creador. Aquí podrás conocer mejor lo que hago y lo que busco aportar a la comunidad de BDFD.

Mi objetivo es seguir aprendiendo, mejorar mis habilidades y compartir proyectos que otros puedan utilizar como referencia para sus propias creaciones.
